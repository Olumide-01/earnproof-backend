REST API ENDPOINTS (6 TOTAL)
================================================================================

1. Create Purpose Definition
   POST /api/v1/organizations/{orgId}/purpose-declarations/definitions
   Required: ORG_ADMIN
   Body: purposeKey, description, disclosureScope
   Response: 201 Created {id, version, ...}

2. Create Declaration
   POST /api/v1/organizations/{orgId}/purpose-declarations
   Required: ORG_ADMIN
   Body: purposeDefinitionId, expiresAt
   Response: 201 Created {id, approvalState: "PENDING", ...}

3. Approve Declaration
   PATCH /api/v1/organizations/{orgId}/purpose-declarations/{id}/approve
   Required: ORG_OWNER or ORG_ADMIN (not requester)
   Body: reason (optional)
   Response: 200 OK {id, approvalState: "APPROVED", ...}
   Behavior: Idempotent (replayed requests return same result)

4. Revoke Declaration
   PATCH /api/v1/organizations/{orgId}/purpose-declarations/{id}/revoke
   Required: ORG_OWNER or ORG_ADMIN
   Body: reason (optional)
   Response: 200 OK {id, approvalState: "REVOKED", ...}
   Behavior: Immediate effect, idempotent

5. Get Declaration
   GET /api/v1/organizations/{orgId}/purpose-declarations/{id}
   Required: ORG_MEMBER+
   Response: 200 OK {id, ...}

6. List Declarations
   GET /api/v1/organizations/{orgId}/purpose-declarations
   Query: approvalState (optional), skip, take
   Required: ORG_MEMBER+
   Response: 200 OK {declarations: [...], total: N}

================================================================================
ERROR CODES (DETERMINISTIC)
================================================================================

NO_VALID_PURPOSE_DECLARATION
  HTTP 403 - No declaration exists for organization
  Recovery: Create and approve a declaration

DECLARATION_PENDING
  HTTP 403 - Declaration pending approval
  Recovery: Wait for approval or resubmit

DECLARATION_APPROVED
  HTTP 200 - Declaration approved (success indicator)
  Recovery: N/A

DECLARATION_REVOKED
  HTTP 403 - Declaration was revoked
  Recovery: Create new declaration

DECLARATION_EXPIRED
  HTTP 403 - Declaration past expiry date
  Recovery: Renew with new expiry date

DECLARATION_ORG_MISMATCH
  HTTP 403 - Declaration from different organization
  Recovery: Create declaration for correct organization

DECLARATION_VERIFIER_MISMATCH
  HTTP 403 - Declaration from different verifier context
  Recovery: Create declaration for correct verifier

DECLARATION_SCOPE_EXCEEDS_POLICY
  HTTP 403 - Purpose scope wider than policy scope
  Recovery: Narrow scope or update policy
